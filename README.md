# School Management System

A web app for managing students, staff, and subjects bult with Flask and SQLite.

## ⚙Features

- **Staff Login**: Secure login for teachers and admins
- **Student Management**: Add, view, and update student records
- **Student Login**: Secure login for students
- **Role-based Access**: Separate dashboards for staff, admins and students
- **SQLite Backend**: Lightweight database, no external setup needed

- **Backend**: Python, Flask
- **Database**: SQLite
- **Frontend**: HTML, CSS, Jinja2 templates, JavaScript
- **Auth**: Flask sessions + Werkzeug password hashing
